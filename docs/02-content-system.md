# 02. Content system

Status: `v0.1 / based on channel history`

Система шаблонов строится не по абстрактным «типам дизайна», а по реальным задачам, которые уже встречались в канале клуба.

## Template A — Single event announcement

Для: ориент-шоу, скалодрома, ночного ориентирования, лекции, тренировки.

### Required information

- короткий hero title;
- category label;
- дата и время;
- место;
- 1–3 причины прийти;
- CTA / registration;
- один hero visual.

### Preferred composition

- strong title;
- 40–60% площади у предметного GPT Image visual или сильной фотографии;
- компактный operational block;
- одна route line.

## Template B — Multi-event calendar

Для: серии мероприятий и планов на несколько недель.

### Required information

- период;
- список событий;
- даты;
- категории;
- единая CTA-механика.

### Visual logic

Не превращать в таблицу мелкого текста. События — последовательность точек маршрута. Каждое мероприятие получает номер / маркер / короткий код.

## Template C — Photo report

Для: открытия клуба, походов, соревнований, ночного ориентирования, поездок.

### Required information

- один эмоциональный тезис;
- место / событие;
- при необходимости CTA на следующий ивент.

### Visual logic

Фотографии доминируют. Бренд работает через рамку, типографику, numbering и route line.

## Template D — Team / sports squad

Для: отбора в сборную, тренировочного процесса, соревнований, результатов.

### Visual logic

Более спортивный и строгий режим:

- black / white base;
- orange route line;
- номера этапов;
- data-first presentation;
- меньше декоративных элементов.

Историческая серия про сборную уже использовала сильную последовательность «создание сборной → тренировочный процесс → соревнования». Новая OS сохраняет эту narrative-модель, но улучшает типографику и визуалы.

## Template E — Expedition / big trip

Для: Безенги и других крупных маршрутов.

### Required information

- название экспедиции;
- даты;
- география;
- уровень требований;
- список критических требований;
- контакт / регистрация;
- дедлайн.

### Visual logic

Hero landscape/photo + generated technical object + route / altitude data.

Пост должен ощущаться как expedition brief, а не обычная афиша.

## Template F — Educational / expert

Для: первой помощи, лекций, техники, теории туризма.

### Visual logic

- эксперт / тема;
- один сильный generated object по теме;
- 3–5 takeaway blocks;
- высокая читаемость.

## Template G — Collaboration

Для: совместных событий клубов ЦУ.

### Rule

Совместный пост не должен ломать бренд клуба. Логотипы партнёров располагаются в отдельной служебной зоне. Визуальный язык основного носителя остаётся единым.

## Template H — Adventure digest

Для: нескольких походов / путешествий / приключений в одном посте.

### Visual logic

Каждая история — отдельная точка маршрута. Карусель может работать как «один длинный трек»: номер, география, короткий текст, фото.

## Production formats

### Social cards

Base aspect ratios to support:

- `4:5` — основной пост / афиша;
- `1:1` — универсальная карточка;
- `9:16` — story / vertical announcement;
- `16:9` — экран / презентационный анонс.

### Presentation

Презентационная система наследует модульность шаблона ЦУ, но заменяет универсальные декоративные объекты на клубные GPT Image assets и route graphics.

### Advertising poster

Плакат должен работать с расстояния:

1. title;
2. hero visual;
3. дата;
4. место;
5. CTA / QR.

Остальная информация вторична и не должна конкурировать с первыми пятью элементами.

## Content density rule

Один носитель — одна главная мысль.

Если текст не помещается без уменьшения до плохо читаемого размера, это не повод уменьшать шрифт: контент делится на карусель / дополнительную карточку / подпись к посту.
