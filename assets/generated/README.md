# Generated assets

Здесь хранятся только отобранные GPT Image visuals со статусом `candidate`, `master` или `deprecated`.

Рекомендуемый путь: `assets/generated/<family>/<object>/<object>_<mode>_vNN.png`.

Каждый asset должен иметь versioned prompt в `prompts/master/`. Логотипы ЦУ, QR, даты, финальная типографика и длинный текст через GPT Image не создаются.
