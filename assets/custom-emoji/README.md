## Как загрузить в Telegram

1. Откройте официальный [@Stickers](https://t.me/Stickers).
2. Создайте новый набор Custom Emoji через **New Emoji Pack**; если бот показывает команду `/newemojipack`, можно использовать её.
3. Выберите формат **Static Emoji**.
4. Загружайте PNG из `telegram-100x100/` как файлы, без сжатия.
5. После каждого файла назначьте один обычный эмодзи из таблицы выше.
6. Опубликуйте набор и задайте короткое имя ссылки.

Чтобы добавить только новые символы в уже созданный набор, откройте управление этим набором в @Stickers, выберите добавление эмодзи и загрузите файлы 21–23 с привязками `🧥`, `📋`, `🧡`.

Telegram требует для статичных Custom Emoji PNG или WebP ровно 100×100 px. Для загрузки используйте только папку `telegram-100x100/`.

## Использование в постах

Обычный Unicode-символ в тексте служит смысловой привязкой, но сам по себе не превращается в клубный Custom Emoji. В редакторе Telegram выберите соответствующий знак именно из опубликованного клубного набора. Так пост сохранит правильный вид и семантику.

Официальные требования: <https://core.telegram.org/stickers>
